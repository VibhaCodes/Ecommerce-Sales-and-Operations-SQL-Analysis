# E-commerce Sales and Operations Analysis

A MySQL project exploring sales, customer spending, seller activity, payments, delivery times, and customer reviews using the **Olist Brazilian E-Commerce Dataset**.

## About the Project

I worked on 14 business questions to practice using SQL for retail analysis. The aim was to connect information from different tables and understand how customers, products, and sellers contribute to marketplace activity.

## Tools Used

- MySQL
- Joins and aggregations
- Common Table Expressions (CTEs)
- Subqueries
- Window functions
- Date functions

## Data Used

The database includes tables for:

- Customers and orders
- Order items and products
- Sellers
- Payments and reviews
- Product category translations
- Geolocation and seller leads

The analysis mainly uses the order, customer, seller, product, payment, and review tables.

## Business Questions

1. How many delivered orders were fulfilled by sellers in each state?
2. How does cumulative revenue grow within each product category?
3. Which payment methods are used most, and what is the average payment value?
4. Which customer spent the most on delivered orders?
5. What is the average review score for each product category?
6. How many orders did each customer place, grouped by their state?
7. Which sellers have no associated orders?
8. Which five product categories generated the most revenue from delivered orders?
9. What is the median delivery time?
10. Which products have never been ordered?
11. Which sellers handled more orders than the average seller?
12. Which customer state has the highest average review score for delivered orders?
13. Which customers have orders without a review?
14. Which month recorded the highest number of orders?

## What the Queries Cover

- **Sales:** Category revenue, cumulative revenue, and monthly order volume.
- **Customers:** Spending, order frequency, and review participation.
- **Sellers:** Regional activity and comparisons with average seller performance.
- **Payments:** Payment method usage and average payment-entry value.
- **Delivery and reviews:** Delivery duration and customer ratings.
- **Product activity:** Products without orders.

## What I Learned

- How to join related tables to answer business questions.
- How to use CTEs and subqueries to break down calculations.
- How window functions help calculate cumulative totals and rank records.
- Why table relationships and the level of detail matter when counting orders or calculating averages.
- How to explain SQL results through a presentation.
